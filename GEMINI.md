# Bridgecore

Bridgecore answers "when X happens, do Y" automation questions with concrete tools:
- `plan_automation` — the concrete tool per step; a missing trigger/action is reported as a gap.
- `find_recipe` — ready-made recipes and 13,000+ public n8n templates.
- `make_n8n_workflow` — an importable n8n JSON with the blanks and accounts listed.
- `do` — the exact HTTP/MCP request for a task, as a preview; nothing is sent.
Docs: https://bridgecore.chinlee2200.workers.dev/for-agents.html
